🔬 Model Architecture

Model: Real-ESRGAN x4plus (RRDBNet backbone) Fine-tuning: L1 + Perceptual + SAM + Edge + Frequency losses Specialty: Satellite-specific multi-loss optimization # SAM (Spectral Angle Mapper) → Preserves spectral curves # Edge Loss → Sharpens roads, buildings, boundaries # Frequency Loss → Recovers micro-textures Input: Sentinel-2 RGB bands (B04/B03/B02) Output: 4× super-resolution (10m → 2.5m equivalent)
